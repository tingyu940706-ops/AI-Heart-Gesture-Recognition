## Core Algorithm

The system extracts body landmarks using MediaPipe Pose and analyzes wrist, shoulder, and nose positions.  
Gesture classification is performed through distance ratio and coordinate relationship analysis.

---

## Demo Results

The system can successfully recognize multiple heart gestures in real time and display the recognition results directly on the screen.
